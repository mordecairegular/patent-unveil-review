# 可观测性与多模态证据职责（测量/诊断/定位类案件必读）

> 来源：同一次测量诊断类案件复盘。三个高频失败模式：①聚合级量测被写成可唯一定位单体内部；②一种证据（如影像/热像）同时包办筛查、定位、归因和决策，落入已有「影像识别→直接处置」拥挤路线；③处置完成即流程结束，缺少复测回写闭环。

## 一、可观测性原则（先测得到，再声称得到）

- **声称的输出精度不得超过输入数据与传感配置能支撑的观测精度**。机器侧由技术证据合同的 `output_rank ≤ observation_rank` 兜底；语义侧仍须核对：输入是否真的含空间/时间分辨信息、是否存在多解（多个原因产生同一观测）、是否需要辅助数据消歧。
- 观测能力不足时的**标准降级措辞**（与 `disclosure_builder.md`「观测粒度匹配」一致）：「确定」→「确定候选」；「定位到」→「映射至可能受影响的」；输出候选集＋置信度；写明引入何种辅助证据后才可进一步细化。
- **数据来源分级登记**：同为"完整曲线/完整数据"也要区分来源——标准条件参考数据（厂家/出厂测试）≠ 现场实时响应。二者用途、时间条件、归一化方式分别登记（合同 `baselines[].kind`），正文不得混写。

## 二、基线分类学

| kind | 含义 | 用途边界 | 更新条件 |
|---|---|---|---|
| `standard` | 厂家/标准测试条件参考 | 仅作对比参考；使用前须做个体偏差、老化或同类统计**校正**；**不得当作现场当前观测** | 型号资料更新 |
| `historical_clean` | 历史正常/洁净/试运行数据 | 当前观测的首选对比基准 | 处置后复测合格时回写更新 |
| `post_treatment` | 处置后复测数据 | 验证判断正确性；合格后升级为新的 historical_clean | 每次处置后 |
| `healthy_peer` | 同类健康对象统计 | 无个体基线时的替代基准 | 样本池变化 |

每条基线登记：来源、用途、适用范围/时间条件、归一化方式、更新条件、**不可用时的替代方案**（优先级链，链尾为「无基线降级模式」）。

## 三、多模态证据职责矩阵

多种证据（如电气/量测信号、可见光影像、热像、物理拓扑、处置后复测）并用时，**先分工再组合**，模板见 `templates/evidence_responsibility_matrix.md`。六种职责：

```text
初筛 → 空间定位 → 机理归因 → 一致性验证 → 决策 → 处置后复核
```

硬规则：

1. **一种证据不得包办全链**——影像不得既定位又归因又直接决策；量测信号擅长筛查与验证，影像擅长空间定位，热异常只是风险线索**不得直接等同于成因判定**。
2. **决策必须是多证据联动的产物**：保留「证据 A 区域 → 物理拓扑 → 预期响应 → 实测一致性验证 → 决策」的联动链；影像/热像识别结果未经物理拓扑与实测一致性验证，不得直接决定处置动作（否则落入「影像识别→处置」已有路线，同时削弱本案联动区别点）。
3. **冲突处理前置定义**：任意两种证据冲突时的裁决规则（谁降级、是否转人工复核）写入决策条件表，不留"视情况"。
4. **物理映射关系须有登记来源**：对象间的结构/连接/覆盖/坐标配准关系来自版型资料、接线记录或标定，**不得由算法臆测**；登记于合同 external 输入的 validity_check。

## 四、处置后复测闭环

处置类方案（清洗/维修/调整/更换）不得在「输出处置方式」处断流：

1. 处置后按同一归一化口径**复测**；
2. 复测结果用于**验证判断**（异常消失→判断确认；未消失→降低原候选置信度，输出替代方案或人工复核）；
3. 复测合格数据满足条件时**回写更新 historical_clean 基线**（合同 `baselines[].update_condition`）。

该闭环通常是可写入从属保护点的真实技术特征，而非流程装饰。

## 五、架构变化触发补充查新（硬门禁）

迭代中发生以下任一**实质变化**时，必须执行**针对性补充检索**，不得沿用旧查新结论直接定稿：

- 数据来源或主要证据模态变化（如从量测信号主线改为影像主线，或反向）；
- 定位方式/观测层级变化（如从聚合级筛查升级为单体内部定位）;
- 核心决策链重构（决策依据、联动顺序变化）；
- 独权主线迁移（原区别特征降为从属、新的主张成为主线）。

补充检索聚焦**新主线的拥挤度**（新路线可能比旧路线更接近已有公开），输出补充查新记录（沿用 `prior_art_search.md` 证据规则），并回写查新等级；等级下调时联动收缩保护点。实证：一次「影像主导定位」的路线试探经补充查新发现该路线已高度拥挤（多模态影像→清洁参数、影像定位→定点处置均有公开），据此回归「量测指纹＋拓扑映射＋一致性验证」主线，固定采样频率降级为常规实施条件。

## 六、Step 8 语义核对清单（本参考的自检落点）

- [ ] 每个「定位/识别/归因」输出的粒度，语义上确由输入证据支撑（不止看 rank 自报）？
- [ ] 标准参考基线未被写成现场当前观测；基线与现场响应换算口径一致？
- [ ] 每种证据的职责与矩阵一致，无一种证据包办筛查+定位+归因+决策？
- [ ] 影像/热像结论均经物理拓扑与实测一致性验证后才进入决策？
- [ ] 处置类方案含复测验证与基线回写闭环？
- [ ] 本轮迭代若发生第五节所列实质变化，补充查新已执行且结论已回写？
