# 候选发明主题卡模板

> 用法：T0.6 按本模板逐张输出（3–5 张，编号 T1、T2…）。卡头声明两条纪律：
> ① 所有等级为探针级初判，案件级正式查新后回写；A/B 级由用户终审。
> ② 检索溯源纪律：每张卡必须带"检索溯源"行；未跑的渠道记"**未覆盖**"，禁止把"未检索"写成"未检出"。

---

## T{n} {方向短名} 【{A/B/C/D/未评级（低置信）} · {探针级初判 YYYY-MM-DD / 案件级查新完成 YYYY-MM-DD}】

- **简洁题名（≤25 字）**：一种{技术对象}{核心处理动作}方法及系统
- **完整技术路线名**：一种基于{关键机制}的{场景限定}{技术对象}{核心动作}方法及系统（仅工作用；限定词不进正式题名）
- **技术问题**：{明确到对象、场景、约束和缺陷；不得是商业痛点原文}
- **核心方案（假说）**：{输入 → 处理机制 → 输出 → 闭环；标注哪些环节有材料支撑、哪些是推断}
- **独权必保留特征（假说）**：①…②…③…（没有它就失去区别点的特征；案件级查新后定稿）
- **独权禁区**：{探针/查新确认的已占据框架，附公开号；禁止写入独权的表述}
- **技术效果**：{必须回扣到机制；标注证据等级：实测/仿真/机理可推导/待验证}
- **工程支撑可行性**：{最小可复现实施例路径：仿真/原型/数据；缺什么}
- **限定依赖度**：{低/中/高}（区分所需 AND 特征数 = {n}；依据：{探针命中或 0 命中组合}）
- **分层**：{主推 / 可发表 / 窄化备选}（窄化备选须注明"保护范围偏窄"）
- **暂停条件**：若发现单篇覆盖"{特征组合}"，则{收缩至X / 与T{m}融合重构 / 放弃}
- **检索溯源**：{渠道×次数、检索式编号、命中概况、来源状态}。**未覆盖**：{未跑渠道清单}
- **用户终审**：{未终审 / YYYY-MM-DD 确认：逐问结论}
- **案件级查新回写**：{留空，Step 5 后回填：结论等级、最接近文献、禁区扩充、暂停条件核销}
